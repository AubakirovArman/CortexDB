# CortexDB Use-case Packs

This directory contains runnable local use-case packs. Each pack points at a
small fixture, a scope, and a CLI smoke flow for search, ContextPack generation,
and verification.

Run:

```bash
make use-case-pack-check
```

Pack manifest:

```text
examples/use_cases/packs.json
```

The public overview is in [`../../docs/USE_CASE_PACKS.md`](../../docs/archive/USE_CASE_PACKS.md).
